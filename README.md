# BIRANGAY

## 🎨 Holi Festival - Immersive Web Experience

An immersive, poetic web page celebrating the Indian Holi festival with vibrant colors, animations, and romantic storytelling.

### ✨ Features

- **Dynamic Particle System**: 50+ animated color particles floating across the screen
- **Interactive Effects**: Mouse-tracking color powder explosions
- **Responsive Design**: Beautiful on mobile and desktop
- **Pure JavaScript**: No dependencies required
- **Canvas Animations**: High-performance particle rendering

### 🚀 Getting Started

Simply open `index.html` in your web browser, or serve it with any HTTP server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve

# Using PHP
php -S localhost:8000
```

Then navigate to `http://localhost:8000` in your browser.

### 🎭 The Experience

The page tells the story of love, freedom, and celebration through:
- Vibrant colors inspired by Holi powder (pink, yellow, blue, green, orange)
- Smooth animations creating a magical floating sensation
- French poetry celebrating romance and joy
- Interactive elements that respond to user interaction

### 📱 Browser Support

Works on all modern browsers with HTML5 Canvas support:
- Chrome/Edge 90+
- Firefox 88+
- Safari 14+
- Mobile browsers (iOS Safari, Chrome Mobile)
